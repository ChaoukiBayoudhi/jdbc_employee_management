# JDBC employee management

A jdbc example using postgresql : Add, Modify, remove, list and find.

## Tech stack

- Java
- Lombok

## Concepts covered

Collections, console input (Scanner), custom exceptions, exception handling.

## Project structure

- `com.company`: DBConnection, Employee, Main
- `com.company.Exceptions`: EmployeeNotFoundException

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.

The JDBC code expects a running database server; set your own connection URL, username and password before running.
